## MRT V4 Roadmap

Material React Table V4 is a community fork of [KevinVandy/material-react-table](https://github.com/KevinVandy/material-react-table), published as `@lminii/material-react-table`.
Its purpose is to keep MRT usable on current Material UI and TanStack Table releases.

### Version 4 (2026)

- Track Material UI and TanStack Table releases. New minors of either are picked up as they ship, and a scheduled CI job builds against the latest versions to catch regressions early.
- Keep the V3 API. The `table` prop, `useMaterialReactTable`, and every `mui*Props` option stay as they are. Breaking changes come only from Material UI or TanStack Table, and are listed in the [V4 migration guide](/docs/getting-started/migrating-to-v4).
- Ship an agent skill for AI coding assistants that teaches the MRT options, the `table` prop pattern and the V3 to V4 renames, building on the skills that TanStack Table V9 already publishes.
- Fix bugs reported against the fork on [GitHub](https://github.com/lminii/material-react-table/issues).

### Not Planned

- Replacing Emotion with Pigment CSS, Joy or Base UI adapters, or other rewrites. The fork does not take on the larger redesigns that were once discussed for upstream V4.
- Merging back into upstream. This fork exists because upstream did not move to Material UI V9 and TanStack Table V9. If upstream picks those up, this fork will point users back to it.

### Upstream

Upstream [Material React Table V3](https://www.material-react-table.com) and its sister library [Mantine React Table](https://mantine-react-table.com) continue to be maintained by Kevin Van Cott.
Use the version switcher in the top bar to open the V3 docs for any page.
