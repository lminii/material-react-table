## AI Agents

Material React Table V4 ships two things for AI coding assistants such as Claude Code, Cursor, Codex, and Copilot.

1. **Agent skills**: ten `SKILL.md` guides that teach an agent the V4 API and the patterns this documentation recommends.
2. **An MCP server**: `@lminii/material-react-table-mcp`, which answers exact questions from the same data as this site.

Skills are the right tool for "how should I build this" and load a few thousand tokens of guidance up front.
The MCP server is the right tool for "what is the type of this option" or "show me the source of that example" and returns only what is asked for.
Use both together when you can.

### Skills

The skills live in the library package under `@lminii/material-react-table/skills` and follow the [Agent Skills](https://agentskills.io) `SKILL.md` format.

<SkillsTable />

#### Install With TanStack Intent

[TanStack Intent](https://www.npmjs.com/package/@tanstack/intent) discovers skills from the packages installed in a project, so the skills are available as soon as `@lminii/material-react-table` is.
The TanStack Table V9 packages ship their own skills the same way, and the MRT skills reference them where a feature is inherited from TanStack Table.

```bash
npx @tanstack/intent@latest list
npx @tanstack/intent@latest load @lminii/material-react-table#getting-started
```

Run `npx @tanstack/intent@latest install` once to add the discovery instructions to your `AGENTS.md` or `CLAUDE.md` so the agent runs those commands on its own.

#### Install With the Skills CLI

Any harness that reads `SKILL.md` files can install the skills straight from the repository with the [skills CLI](https://github.com/vercel-labs/skills).
Pass `-a claude-code`, `-a cursor`, `-a codex`, `--all`, or another supported agent.

```bash
npx skills add https://github.com/lminii/material-react-table/tree/v4/packages/material-react-table/skills -a claude-code
```

### MCP Server

The [`@lminii/material-react-table-mcp`](https://github.com/lminii/material-react-table/tree/v4/packages/material-react-table-mcp) package is a stdio [MCP](https://modelcontextprotocol.io) server.
It runs locally, needs no network access after installation, and requires Node 22.12 or newer.

Claude Code:

```bash
claude mcp add material-react-table -- npx -y @lminii/material-react-table-mcp
```

Any client that launches stdio servers, such as Cursor, Windsurf, or Claude Desktop, takes the same command in its MCP configuration:

```json
{
  "mcpServers": {
    "material-react-table": {
      "command": "npx",
      "args": ["-y", "@lminii/material-react-table-mcp"]
    }
  }
}
```
